# web-001 视觉证据说明（无二进制）

> 题包禁止提交二进制截图；本文件规定验证侧应采集的截图与人工复核要点。截图由 Playwright 在验证沙箱内生成，存对象存储，文件名与断言绑定。

## 1. 必采截图

| 编号 | 时机 | 视口 | 用于 rubric |
| --- | --- | --- | --- |
| S1 | 初始加载（浅色） | 1280×800 | R8/R10 基线 |
| S2 | 拖拽过程中（卡片半透明/落点高亮） | 1280×800 | R12 |
| S3 | 跨列拖拽完成后 | 1280×800 | R1/R3 |
| S4 | 清空 todo 后（空状态可见） | 1280×800 | R6 |
| S5 | 暗色模式 | 1280×800 | R7/R10 |
| S6 | 键盘移动后 | 1280×800 | R4/R5 |

## 2. 采集脚本要求

- 截图由 Playwright 在断言之间的确定时刻采集（使用 page.screenshot 指定 path），文件名 s1-initial.png … s6-keyboard.png；
- 每张截图附：断言 ID、页面 URL（http://127.0.0.1:4173/index.html）、浏览器版本、时间戳；
- 截图连同 sha256 写入 trial 的 result.evidence，供裁判引用（裁判只能基于这些证据判 R10/R12）。

## 3. 人工复核要点

1. 暗色模式下三列卡片与页面背景是否同色系（R10）；
2. 拖动过程中是否有落点提示（R12）；
3. 清空列的提示文字是否出现在列底部而非页面顶部（R6）；
4. 键盘操作后的焦点位置是否仍可见（R4/R5 辅助）。
