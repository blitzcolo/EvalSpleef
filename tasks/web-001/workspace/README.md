# 团队看板（起始代码）

一个没有任何构建步骤的单页看板：HTML + CSS + 原生 JS，数据在 `app.js` 里。

## 运行

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```

## 已有功能

- 三列看板（待办 / 进行中 / 已完成），卡片静态渲染；
- 列头有卡片计数（当前逻辑不对，见下）；
- 顶部有「切换主题」按钮（当前没有效果）；
- 每列底部预留了空状态提示（当前永远隐藏）。

## 已知问题

- 卡片拖不动：拖动只在页面内高亮，松手不落位、不保存；
- 看不到键盘操作：无法用方向键移动卡片；
- 切换主题按钮没有反应；
- 列计数在移动卡片后不会更新；
- 空状态永远不显示。

## 约定

- 保留所有 `data-testid` 与 `data-column` / `data-card-id` 属性（验收依赖这些钩子）；
- 不要引入构建步骤（保持单页可直接打开）；
- 初始卡片数据放在 `app.js` 顶部，刷新后应从 `localStorage` 恢复。
