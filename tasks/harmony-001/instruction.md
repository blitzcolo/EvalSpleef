# 帮我做个手机上的图片小工具

我在做一组要发到社区的照片，手机上想随手处理一下：转灰度、整体提亮一点、拉一下对比度、做个柔化、再能转个方向。系统相册里挑一张图，点一下按钮，预览区**立刻**看到效果。

现在工程里界面壳子和按钮都在了，但点了没反应。工程里有一份接口说明，**那个文件别改**，照着它把处理逻辑补上；另外工程里已经声明了界面层要用的类型，也别改。

## 要求

1. 选图用系统相册选择器就行，不需要申请读取相册的敏感权限。
2. 五个动作都要能用：灰度、提亮、增强对比、模糊、顺时针旋转 90°。
3. 处理完的图片要能继续在预览区显示；旋转后长宽方向要对。
4. 处理大图时界面别卡死，也不要因为一次处理失败就闪退——失败给我一句中文提示就行。
5. 图像处理要落在原生侧（工程里预留了位置），不要在界面层用别的图像库绕过去。

## 交付

- 能构建、签名、装到我手机上跑起来的 HAP；
- 五个按钮都能看到效果；
- 处理结果和原图对比，颜色/方向符合常理（比如灰度后不应偏色）。

构建、签名、装机、看日志的命令在工程 README 里有；签名材料我已经放在平台上了，别自己去注册开发者账号。
