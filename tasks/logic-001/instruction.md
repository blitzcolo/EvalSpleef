# 帮我破解 5 组「数字机关」对局记录

我朋友做了个小游戏：6 个格子里各有一个 0-9 的数字，两名玩家轮流按**同一个隐藏规则**推一下棋盘。游戏会记下每回合结束后的棋盘，但从来没把规则写在任何地方。

我手里有 5 组记录，每组是连续几次推完之后的棋盘快照。规则肯定在这一族里（他写代码的，规则只有这几种组合）：

**每回合：先按一个位置置换重排 6 个格子，再对每个格子做一次 f(x) = (a·x + b) mod 10。**

位置置换是这样定义的（设 old 是推之前、new 是推之后，都是 6 个数字的列表）：

| 名字 | new 的第 i 格取自 old 的第几格 |
| --- | --- |
| id | [0, 1, 2, 3, 4, 5] |
| rev | [5, 4, 3, 2, 1, 0] |
| rot_l1 | [1, 2, 3, 4, 5, 0] |
| rot_r1 | [5, 0, 1, 2, 3, 4] |
| swap_halves | [3, 4, 5, 0, 1, 2] |
| rot_halves | [1, 2, 0, 4, 5, 3] |
| evens_first | [0, 2, 4, 1, 3, 5] |
| rev_halves | [2, 1, 0, 5, 4, 3] |

也就是说 new[i] = (a · old[perm[i]] + b) mod 10，其中 a ∈ {1, 3, 7, 9}，b ∈ 0..9。

**举一个做好的例子**（这不是给你的 5 组之一，只是演示怎么核）：某组第一个棋盘是
`2, 5, 0, 7, 1, 8`，推一次后是 `6, 3, 4, 1, 7, 2`。
先试 rev：new[0] 取 old[5]=8，(3·8+2)%10=6 对得上，可 new[1] 取 old[4]=1，(3·1+2)%10=5，记录上却是 3 —— 矛盾，排除 rev。换 rot_l1、a=7、b=4 时 new[1] 取 old[2]=0，(7·0+4)%10=4，记录是 3，也矛盾。真正这一例是 perm=evens_first、a=3、b=7，你代入所有位置都能对上。

（上面这个例子我手写的，就当练手；真正要解的是工作区里那 5 组。）

## 输入

工作区里有一份 `instances.json`，结构是：

```json
{"instances": [{"id": 1, "boards": [[...6 个数字...], [...], [...]]}, ...]}
```

每组的 `boards` 是连续快照：`boards[0]` 是初始棋盘，后面每一次都是推一下之后的棋盘。这 5 组的规则都在上面那一族里，而且**记录足够唯一地确定规则**（这是出题人保证的），所以下一回合的棋盘只有一个正确答案。

## 你要交的

在 `/workspace/answer.json` 写一个 JSON 文件（写在工作区里，别交到聊天窗口）：

```json
{
  "instances": [
    {
      "id": 1,
      "rule": {"perm": "rev_halves", "a": 3, "b": 7},
      "next": [0, 1, 2, 3, 4, 5],
      "derivation": "用第 1、2 个棋盘的第 0 格和第 4 格建立两个同余式，解出 a 与 b；其余 7 种置换逐一代入记录均在第 2 次转移处矛盾，故置换唯一。据此得到下一棋盘。"
    }
  ]
}
```

规则：

1. 5 个实例都要写，`id` 从 1 到 5，不能重复、不能少；
2. `rule.perm` 必须是上表里的名字，不能自己起名；`a`、`b` 是整数；
3. `next` 是 6 个 0-9 的整数；
4. `derivation` 写 1-3 句、不超过 300 字，要让我看出你**怎么从记录里排除其他可能、为什么结果唯一**；可以引用具体格子和数值，但别贴代码；
5. 答案文件里只放这个 JSON，不要加注释、标题、寒暄，也不要把其他内容写进同一文件；
6. 别动 `instances.json`，我这边要对原始记录。

用什么办法推都行，手算、写脚本都可以。做完告诉我一声。
