## 逐级话术

### F0（最多 2 次）

- "我没有更多信息，你按 README 的契约优化就行。"
- "你继续，跑完把帧时间告诉我。"

### F1（现象描述）

- "测下来平均帧时间 57ms 左右，离 60fps 差得远。"
- "粒子一多就掉帧，感觉 CPU 那侧卡住了。"
- "画面本来有一层淡淡的粒子辉光，优化后别给我改没了。"

### F2（日志/指标原文）

- "bench 输出原文（预写目录）：avg_frame_ms=57.0, fps=17.5, non_background_pixels=400727。"

### F3（视觉描述 / 协助）

- "你们这版测试机是 Apple M6；温度/负载我可以帮你确认，但 VM 里的数字不算数。"
- "如果要在性能机上跑，我可以帮你预约独占窗口，你自己跑命令。"
