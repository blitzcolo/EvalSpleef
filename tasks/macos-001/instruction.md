# Metal 粒子渲染优化：从 20fps 到 60fps

我们有一支 macOS + Metal 的粒子渲染基准程序 **ParticleBench**（工作目录下，用 make 构建）。它现在的性能离目标差很远：24000 个粒子、1920x1080 下平均帧时间约 57ms（约 17.5fps），而我们需要稳定到 **60fps 以上**（平均帧时间 <= 16.7ms）。

请优化这份实现，让它在不改变画面元素的前提下达到 60fps 目标。要求：

1. 先读 **README.md** 的契约：构建方式、JSON 输出字段、功能与性能门槛、入口参数语义都不能变。
2. 不得改变画面元素：非背景像素占比与基线保持同一量级（>=1% 画面）。
3. 不要修改 **tests/** 下的文件（验收会核对测试文件哈希）。
4. 性能验收在**裸机性能机**上执行：5 次独立运行的 avg_frame_ms 取中位数，必须 <= 16.7ms。
5. 自测：

       make bench
       ./build/ParticleBench --frames 120 --particles 24000 --width 1920 --height 1080

完成后说明你的优化手段与实测帧时间。
