# 从头搭一条 Vulkan 管线，画个带阴影的场景

我想验一下图形这条线，题目是：用 Vulkan（C++）从空工程开始，渲染一个很简单的场景——

- 一块深灰的地面，中间立一个青色的方块；
- 一束方向光从左上角照下来，方块要在地面上投出**看得见、边缘不太硬**的阴影；
- 窗口 800x600，跑起来不闪、不崩。

工程里已经给了构建脚本、一个渲染骨架、几个着色器草稿，还有一个阴影数学的接口文件。**接口文件不要改**，把里面声明的东西实现出来，再让整条管线跑通。

## 硬要求

1. 必须开 Khronos 验证层（`VK_LAYER_KHRONOS_validation»）并装 debug messenger。**验证层报 error 就算没做完**。
2. 阴影贴图要真的用上（深度图 + 采样），不许把阴影画死在纹理里。
3. 按 `S» 存一帧到 `out/scene.ppm»（P6、800x600），平台会拿它跟参考图比相似度。
4. 阴影数学（光源矩阵 + 3x3 PCF）写在指定文件里，要能被普通 C++ 编译器单独编过（评测会做 CPU 数值测试）。

## 交付

- 能构建、能跑、验证层干净的工程；
- `out/scene.ppm» 截图；
- 阴影形态自然：光从左上打下来，影子落在地面右下方向，边缘有轻微软化。

有 GPU 节点；如果手头只有软件实现，功能可以先跑通，但最后要在 GPU 节点上出一张截图。
